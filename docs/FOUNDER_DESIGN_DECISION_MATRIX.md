# Founder design decision matrix

Three directions, fourteen dimensions, one estate.

**No winner is named here, and nothing is scored.** Every cell is an observation about what the
direction does — not a judgement about whether it does the right thing. Two of these dimensions
will matter to you far more than the other twelve, and which two is the decision.

Read this beside `FOUNDER_REVIEW_INDEX.html`, which shows the same three directions as pictures.

- **A — Canonical light.** Precise, ruled, operational. Dense but calm.
- **B — Graphite console.** Explanatory, answer-first, grouped, guided.
- **C — Hybrid executive.** Editorial, spacious, strong hierarchy, restrained.

All three read the same ten installations across the same four projects, at the same moment,
through the same control plane the live screens read.

## Facts that apply to all three

These are not differentiators. They are stated so a dimension above is not read as a trade-off
that any direction actually makes.

- **The three states are never collapsed.** Activation, connection and ingestion are three
  separate readings with three separate words in every direction, on every screen. A verdict word
  appears beside them and is a precedence, not a summary.
- **An absence is never a zero.** A counter nobody reported reads as "Not reported" with the
  neutral mark, in a different weight and colour from a measurement. A reported zero reads as `0`.
- **A state is never carried by colour alone.** Every mark has a word beside it; the shapes carry
  the meaning for a reader who cannot separate the colours.
- **The activation code is a labelled sample in every direction.** The real plaintext exists for
  the length of one server response and is never stored, so no direction shows a real one.
- **Nothing in the lab acts.** Every control is `type="button"` with no handler.
- **No decorative charts.** There is no sparkline, trend or score anywhere in the round.

## What this round did not measure

- **Long-term legibility.** Every judgement here is from a single sitting. None of the three has
  been lived with.
- **Print and export.** No direction has been tested as a PDF or a printed page.
- **Localisation.** All copy is English. Two of the three set state words in fixed-width columns,
  which is where a longer language would land first.
- **Real photography of the stress estate.** Fifty installations were rendered and asserted
  against, never captured: the pictures in the review package all show the true ten.
